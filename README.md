# Prayecto_IoT
# Diseño e implementación de un sistema IoT para el monitoreo inteligente de un aula

## Descripción del proyecto

Este proyecto consiste en el diseño e implementación de un sistema IoT
orientado al monitoreo inteligente de un aula.

El sistema permite supervisar diferentes variables ambientales con el
objetivo de facilitar el seguimiento de las condiciones del aula y
contribuir a una gestión más eficiente del entorno.

## Variables monitoreadas

- 🌡️ Temperatura
- 💧 Humedad
- 💡 Iluminación
- 🌫️ Calidad del aire

## Tecnologías utilizadas

- ESP32
- Sensores IoT
- Cisco Packet Tracer
- Redes de comunicación
- Plataforma en la nube

## Objetivo

Diseñar e implementar una solución IoT que permita monitorear variables
ambientales de un aula, utilizando dispositivos conectados, una red de
comunicación y una plataforma para la visualización de la información.
